# LuzTech Mesh Generator

A fully static website for generating LuzTech brand mesh gradients — both
static images and animated videos — built with React, TypeScript, Vite, and
[Editframe](https://editframe.com).

## Features

- **Image tab** — generate a static (non-swirled) mesh gradient at any size and
  download it as a PNG. Rendered client-side to a canvas; no server required.
- **Video tab** — generate an animated (swirled) mesh gradient with configurable
  width, height, FPS, duration, and speed, then render it to MP4 entirely
  in-browser via Editframe's `renderTimegroupToVideo` (WebCodecs).

## Brand colors

The default palette matches the LuzTech typography mesh gradient:

- Top left: `#00ff9d`
- Top right: `#69dd96`
- Bottom left: `#4665c3`
- Bottom right: `#1f6fef`

## Mesh gradient references

- **Static image** — the non-swirled mesh is modeled after the
  [Mesh Gradient Generator](https://meshgradient.com/) (by Burak Aslan). The
  static image intentionally has no swirl; it uses the
  `StaticMeshGradient` shader from
  [`@paper-design/shaders-react`](https://www.npmjs.com/package/@paper-design/shaders-react).
- **Animated video** — the swirled animation reuses the same
  `@paper-design/shaders-react` `MeshGradient` shader as the existing Remotion
  project in [`../animations`](../animations), so the rendered video stays
  faithful to the brand animation.

## Development

```bash
npm install
npm start          # live preview at http://localhost:5173
```

## Build

```bash
npx vite build     # outputs a single self-contained dist/index.html
```
